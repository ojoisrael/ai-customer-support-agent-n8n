# Security Policy

## Supported Versions

This repository is a portfolio and demonstration project. The latest version on the default branch is the supported version for security reports.

## Reporting a Vulnerability

If you discover a security issue in this project, please do not publish sensitive details in a public GitHub issue.

Instead, contact me through the contact information on my portfolio:

https://ojo-israel-portfolio.lovable.app

Please include:

- A clear description of the issue
- Steps to reproduce it
- The potential impact
- Any relevant logs or screenshots, with secrets and personal information removed

## Secrets and Credentials

This repository is intended to contain only sanitized example configuration and workflow files.

Do not commit:

- API keys
- Access tokens
- Passwords
- Webhook secrets
- Database credentials
- Private customer information
- Personal authentication data

Use environment variables or your n8n credential manager for real credentials.

The workflow JSON included in this repository has been sanitized for public sharing.
